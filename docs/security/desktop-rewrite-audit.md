# Desktop rewrite audit — 2026-10-14

Scope: the locally implemented Rust editor, project/catalog input, command history, presentation, asynchronous rendering/reads, export, save/recovery and build/launch wiring. The reference checkout was consulted for migration behavior only; no external application source or assembly became a build input. This is a local source review with executable regressions, not independent attestation or full Achiever parity acceptance.

## Confirmed findings and fixes

Each row describes a reproducible pre-fix path. Input prerequisites are ordinary editing for history/settings issues, control of project/CSV files for parsing/render graph issues, competing local writes for ownership issues, and asynchronous completion timing for preview/read issues. These findings are confirmed by the source paths and regressions listed below; they do not imply an installed-process escape.

## Verification and scope limits

The toolbar/layer restoration extends the in-process presentation port with host-owned layer/asset previews and bounded layout/style persistence. `ImportLayerImage` is a fixed local image intent; the host pins project identity while the in-app dialog is open and commits the library/recipe update in one validated command. It adds no worker operation or launch path. Style edits validate the candidate document and recipe before the host saves the library; failed or corrupt state writes preserve the previous file. Layer deletion, cloned folder/mask/effect identity remapping, channel-mapping coverage, selective-color ranges, sparse-recipe paint preservation and inactive-root undo grouping have executable regressions. These are local data/UI checks; exact reference appearance and native floating-window interaction remain separate acceptance work.

Run the complete source/fixture suite with `build/Audit.ps1 -Offline -Fixtures -DependencyAudit`. It includes strict full-workspace lint, Rust regressions, receiving policy, protocol/ownership, installer helpers, migration, worker provenance, synthetic Chromium and the desktop dependency restrictions. Fresh evidence records the exact source digest and each gate; native editor/color screenshots are explicitly selected separately.

The Rust advisory database used for the check is revision `7eebec69c352c7191b1f13eb95dd510eeca5d1de`, committed 2026-10-09. Raw findings still include the pre-existing RSA private-key timing advisory, with the existing expiring [public-verification-only exception](dependency-exceptions.json). No new exception was added. This scan excludes registry yanked status and managed/Chromium vendor advisories.

The UI still shares the supervised host process; dependency/source restrictions are architecture drift checks, not a malicious-code sandbox. Cooperating saves are serialized on Windows; unrelated same-user writers and filesystem replacement races are not fully isolated. Paired recovery is not a filesystem transaction, and export has no crash-recovery journal. Primitive image/font/filter work cannot be forcibly interrupted mid-call; whole-process CPU/RSS and sustained fuzzing are unqualified.

Installed ACL/WFP/browser enforcement, live Steam sign-in, real-user desktop acceptance and reference pixel parity were not exercised by this source audit. Remaining workflows are explicit in the [parity ledger](../desktop-rewrite.md); this audit does not declare the entire rewrite finished or every possible defect eliminated.
