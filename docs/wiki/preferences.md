# Preferences controls and workspace layout

Open File > Preferences. Save applies the draft. Cancel, closing or Escape discards its appearance preview.

Project settings and application Preferences have different scopes. Project settings contain the game association, atlas/output and unachieved icon configuration.

## General

General shows the Achimeld settings folder, Choose folder, current logging location/status, Open log folder and View logs. Shared preferences, gradients and icon styles live in the settings location; project localization remains beside its .achv file.

Language changes the editor interface, not achievement translations.

Layer properties in right sidebar is on by default. It keeps Layers compact and puts selected layer/effect controls in Properties. Off restores the combined layout. Show layers panel recovers the floating stack.

Display mini values in FX rows is on by default. It controls compact parameter editors; full properties remain available even when narrow rows omit them.

## Colors

Edit palette entries using swatches. Restore default colors returns the default palette in the Preferences draft. Inspect selected, disabled, hover and focus states as well as ordinary controls before saving a palette.

## App style

| Setting | Exposed range |
| --- | --- |
| Control corners | Square for all buttons and panels |
| Heading font size | 10-48 |
| Normal font size | 9-32 |
| Small font size | 8-24 |
| Knob label font size | 8-24; default 10 |
| Knob value font size | 8-24; default 10 |
| Inspector spacing | 0-32 |
| Minimum label width | 40-240 logical pixels |
| Label width budget | 5-50 percent |

Button/tab and knob previews help inspect the draft. Field-label settings affect resizable editors. Labels stay on the left; abbreviations are enabled by default and hover reveals their full text. Fixed forms retain complete labels.

Hover the gap between label and field to reveal a divider. Dragging changes the shared label ratio. Inside Preferences it remains part of the draft; Save/Cancel retain their usual meaning.

## Naming and Browser

Naming sets Achievement naming convention and shows a generated example or validation error. It influences newly generated identifiers rather than translating existing display names.

Browser explains that Steam uses a separate browser with manual sign-in and retained session; it shows current status. Profile open/delete actions are in the Steam/Sync workflow.

## Work with controls

Type numeric values directly or drag their controls. Range controls have separate endpoints and a movable bar; use arrows for focused values and Shift for larger changes. Hover abbreviated labels and icon-only actions.

The color window is movable and supports visual/RGBA/hex editing; [Gradients](gradients.md) explains it in context.

Windows > Set window size sets the main dimensions. Windows > Reset layout recovers workspace panels. Canvas cameras, Style Viewer preview framing and floating panel layout are separate pieces of presentation state.
