# Gradient Explorer

Open **Tools > Gradient Explorer…**, or **Gradient presets > Gradient Explorer…** in a gradient layer or effect. The window shares the existing local gradient library, including migrated original-app presets. Browse named gradient tiles, create or duplicate a gradient, edit its stops and opacity, and save it. Plain-click selects one tile; Shift-click adds a tile to the selection, and Alt-click subtracts it. **Delete selected** or the Delete key while a tile has focus removes the entire selection in one host-owned transaction. **Undo delete** restores the whole removed group. **Export selected…** exports all selected tiles. Search retains only selections visible in the filtered results. Switching presets, starting file operations, or closing the window saves the current valid draft; invalid names stay open for repair. Library edits do not change the project or its undo history. Choose a saved preset from any layer/effect's existing Gradient presets menu to apply it through normal project history.

**Import…** reads a Photoshop `.grd` set. **Export selected…** and **Export all…** write Photoshop `.grd` sets, retaining names, colors and transparency. Native Windows pickers select files; the supervised host owns all file access. Exports publish complete files without replacing existing destinations. Imports validate the entire set before persisting it, so a rejected file leaves the library unchanged.

Double-click empty space in any gradient editor to create a stop at that position, using the existing gradient color. Right-click creation remains available for 1D gradients. In 2D maps, double-clicking creates and selects a sampled color point; its controls appear below the map. Click-and-release on empty map space tests a slice, while dragging empty space draws a selection box. Shift-click adds points to the selection, Ctrl-click removes them, and dragging a selected point moves the group. All points, including the initial edge points, can move or be deleted. The 64-point limit remains in place; the map's action bar includes Delete and replaces the point edit menu.

## Format and limits

The codec uses the Photoshop 6+ `8BGR` version-5 format and version-16 ActionDescriptors. It writes custom solid RGB gradients, with separate color and opacity tracks, UTF-16 names, midpoint 50 and interpolation 4096. Positions use Photoshop's integer 0–4096 range, so export quantizes offsets to 1/4096. On import, the two tracks and their midpoint knots are combined into Achimeld's linear RGBA stops; coincident hard edges retain both sides. Photoshop interpolation/smoothness and newer perceptual color methods are rendered with Achimeld's existing linear interpolation; exact Photoshop pixel parity is not claimed.

The reader accepts at most 8 MiB, 512 presets, 128 stops per source track and 128 combined stops per gradient. Descriptor depth, field/list counts, strings and total nodes are bounded. Legacy version-3 files, noise gradients, dynamic foreground/background stops and non-RGB color spaces are rejected with a specific error. A modern `8BIMphry` folder trailer is ignored; imported presets appear as a flat library.

Format references: [Adobe's ActionDescriptor specification](https://www.adobe.com/devnet-apps/photoshop/fileformatashtml/), and the [GRD format author's documentation and Photoshop generation scripts](https://github.com/Investigamer/json-photoshop-scripting/blob/master/Documentation/Photoshop-Gradients-File-Format/README.md). These are format references, not live Photoshop qualification. Tests cover an independently assembled descriptor fixture, separate opacity/midpoint knots, Unicode, hard edges, export/import, malformed and truncated files, atomic library persistence and refusal to replace an existing export. Native captures inspect the explorer and color picker at normal and increased display scale. A live Photoshop import/export check remains unqualified.

## Color picker

Gradient handles, gradient point maps and color swatches share a movable color window. Drag its title bar to reposition it. Visual controls are 70% of their former dimensions, with fixed square saturation/brightness geometry and full-width hue and opacity strips. RGBA fields keep their width independently of their current digits. The **Hex** field accepts `#RRGGBB` or `#AARRGGBB`, with or without `#`; incomplete or invalid text leaves the current color intact. Mouse dragging and keyboard arrow controls remain available.
