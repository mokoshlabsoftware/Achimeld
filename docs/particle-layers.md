# Particle layers

Add **Particles** in the Icon layers picker. This is a procedural, static artwork layer; previews and exported icons use the same SDF compositor.

The inspector begins with the same compact icon action bar as Explosion: mask, presets, load/save, randomize and the achievement-specific seed switch. Count, seed, Size, Rotation, Shape X/Y, Opacity, SDF softness and Regularity appear before the spawn diagram and component editor. Shape X/Y independently stretch the complete composite by 1–10× in the particle's rotated local axes. Regularity uses Explosion's direction: 0 distributes positions evenly across the spawn disk/annulus; 1 keeps the original fully random distribution. Intermediate values progressively jitter the even distribution. The existing center, radius and edge-bias controls still apply.

Star components use a two-handle **Inner radius** range. Each particle samples a stable radius within the component's bounds using a separate random stream, so changing this range or Shape X/Y preserves its other sampled values. Legacy stars start with coincident handles at their saved radius. Neutral Shape X/Y and Regularity defaults preserve existing appearance; both recipe validators bound axes to 1–10, Regularity to 0–1 and ordered inner radii to 5–100%. Saved projects, single effects and Explorer collections retain these values. Rendering and work admission use the same rotated, stretched bounds and the existing render work cap.

Numeric properties use the compact filled knobs shared with the layer opacity controls, with adjacent numeric fields. Random seed uses an input field. Size, rotation, opacity, SDF softness and spawn radius have two round knobs for the minimum and maximum. Drag either knob independently, or drag the blue bar to move both ends together while preserving their separation and respecting the slider limits. The bar highlights on hover; knobs retain their normal color when selected. Arrow keys adjust the focused knob or bar, with Shift for larger steps. The minimum radius defines an inner exclusion circle. Distribution runs from a concentration near the inner radius through an even disk/annulus to its outer edge. Drag the spawn-center gizmo or use the X/Y sliders. Coordinates and radii are relative to layer space; particle diameters use the existing 512-unit artwork space.

The **Particle shapes** list sits to the right of the spawn diagram when there is room and stacks below it in narrow inspectors. Each particle uses the entire ordered composite. Add spheres, polygons or stars, select a part and adjust its scale, position, rotation, sides and star inner radius. The first part starts the shape; later parts use Union, Subtract or Intersect. The Ring preset demonstrates a sphere with a smaller sphere cut out. Composite bounds are normalized so the Size range continues to describe the overall particle diameter.

New particle layers use a **2D color map**. Its vertical axis describes the colors along a particle's gradient, from top to bottom; its horizontal axis describes variation between particles. Each particle selects a distinct, seeded random vertical slice and overlays that complete 1D gradient within its shape. Choose Linear or Radial placement and adjust the linear angle. Slices use a separate random stream, so adding a color map does not change existing geometry. Stratified, shuffled selection covers the map without repeating a slice. The achievement-specific seed switch changes both layout and slice selection.

The map starts with 12 points along the edges, black along the top, white along the bottom and gray along the sides. Every point can be selected, moved and deleted, including these initial edge points. Handles and selection rings are twice their previous physical size; selected points stay visible when the pointer leaves the map. Click a point to select it, Shift-click to add it to the selection, and Ctrl-click to remove it from the selection. Drag empty map space to draw a selection box; Shift and Ctrl also add or subtract the boxed points. Drag any selected point to move the entire group while retaining its spacing. Group motion clamps together at the map boundaries and rejects collisions atomically. Arrow keys nudge the selection, with Shift for larger steps. The action bar's **Delete** button and the Delete key remove the selection. Double-click empty space to create a sampled color point. There is no point edit context menu.

The selected points' color, position, Power and X/Y influence appear in aligned rows below the map. Position fields translate the selection as a group; color and influence edits apply to every selected point. Click the swatch to open the movable color editor, which includes visual controls and RGB/alpha-inclusive hex entry. Deleting all points leaves a valid transparent field; a double-click can add its first point again. Inverse-color handles become lighter around middle gray so they remain visible.

The field blends all points with normalized anisotropic distance weights (Shepard interpolation), giving a smooth Voronoi-like color field without abrupt cell boundaries. Power changes a point's relative contribution; the independent X/Y ranges stretch its influence. Colors blend with premultiplied alpha, so transparent points do not add dark fringes. The **Test slice** knob moves the vertical guide from left to right and displays the resulting top-to-bottom gradient in the strip beside the map. A single click-and-release on empty map space also positions this helper; pressing, drawing a selection box and dragging points leave the guide unchanged. The guide and point selection are editor-only state: they do not change the effect, its random choices or the undo history. The native review preview shows one effect image and a seed input that refreshes that image.

Black to white, Aurora, Soft spectrum and Warm and cool are color-map presets. Soft glow, Star field, Confetti and Ember ring are built-in effect presets; shape presets are separate. Existing recipes without `particles.colorMap` retain their 1D gradient, including legacy spawn-radius/random color placement. **Use a 2D color map** seeds a new map with the old stop colors when conversion is requested.

**Different seed for each achievement** keeps the recipe's base seed shared while deriving a stable layout from each achievement identity. Switching it on updates previews. Saving/reopening, undo/redo and export preserve that layout; duplicating an achievement gives the copy its own variation. Randomize changes the base seed. Effect presets preserve the current seed and this switch; loading a saved effect restores its saved values.

The dice button at the end of the lower layer bar, **Re-roll all random layers**, gives every Particle, Explosion and Perlin noise layer in the current icon a fresh seed in one undoable edit. It includes hidden layers, folder contents and mask sources regardless of the selected layer. Other settings and achievement-specific seed switches stay intact. The button is disabled when the icon has no random layers.

**Load effect…** and **Save effect…** use standard Windows file pickers and portable `.achparticles` JSON. The file contains all particle settings, component shapes, color-map points and influence, gradient placement, variation ranges and seed options. Common layer transforms, blend mode, folder relationships and other layer effects remain part of the enclosing icon recipe. Preset reads are capped at 256 KiB and validated before normal undoable layer/style editing applies them. A pending load is pinned to its project, achievement, layer and revision. The supervised host owns all file access; no worker command or browser operation is added.

The limits are 512 particles, 16 component shapes, 16 polygon sides/star points, 64 color-map points, 128 legacy gradient stops and the existing icon render budget. The unchanged color-map wire shape now accepts 0–64 movable points in both Rust and managed validation; initial edge positions are defaults rather than mandatory anchors. Duplicate points, invalid colors, nonfinite coordinates, positions outside the map and unbounded influence remain invalid. Saved projects and effect presets preserve moved, removed and empty point sets. The renderer estimates clipped shape work and slice sampling before rasterizing and checks cancellation during rasterization. Map edits paint a 64×32 preview immediately, then refine to 256×128 on a single bounded background worker with one queued job. Obsolete map work is cancelled. A single map texture cache per UI context uses linear mipmaps; particle canvases retain the existing quick/final preview pipeline.

The generated particle icon source, exact imagegen prompt and embedded transparent glyph are retained under `crates/achimeld-ui/assets/toolbar/particle-icon.json` and `layer-particle*`.

**Particle Explorer**, available from Tools or the layer's presets menu, manages a named library with live previews, search, save, duplicate, remove/undo removal, and portable collection import/export. Its `.achparticles` collections embed the full particle settings, component shapes, seeded variation, gradient stops and transparency, 2D color-map points/influence, plus layer opacity, blend, transforms and effects. Colors are independent copies, with no dependency on the gradient library. Import accepts earlier single-effect `.achparticles` files too; the older Load/Save effect actions retain their single-effect format and scope. Applying an Explorer preset uses normal layer undo and preserves the target identity and folder/mask links.

The shared **Reverse gradient** icon mirrors all 1D stops and their transparency. Above the 2D color map, it reverses each particle's gradient from top to bottom while preserving horizontal variation. Untouched legacy edge layouts retain their original point ordering; edited point sets are mirrored vertically. Click the selection's color swatch to open its color picker; there is no separate Color button.
